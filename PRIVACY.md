# Privacy policy

Color Collapse for Fabletics runs only on fabletics.com pages.

- It does not collect, store, or transmit any personal data, browsing history,
  or analytics.
- The only data it keeps is your own settings (whether collapsing is on, the
  two grouping options, and where you placed the on-page button). These are
  stored with Chrome's extension storage, which may sync between your own
  Chrome profiles if you have Chrome sync turned on. Nothing is sent to the
  extension's author or any third party.
- The extension makes requests only to the same product-search service the
  Fabletics site itself uses, from within the page, in order to load the
  product list it then de-duplicates. No request goes anywhere else.
- There is no remote code. Everything the extension runs is in the package
  you install.

Questions: open an issue in the project repository.
